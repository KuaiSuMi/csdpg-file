# 学术基线复审结论

更新：2026-11-13。按本次确定的范围，学术基线保留 **Infer/Pulse + feTruth**，商用保留 AppCAT + NeuVector。BARO、Parfum、GLITCH、Kivi、Reynard 不再占当前主基线名额；既有实验保留为历史材料。

| 项目 | Infer/Pulse | feTruth |
| --- | --- | --- |
| 正式论文 | CAV 2020，CCF-A | ESEC/FSE 2023 Research Papers，CCF-A |
| 任务 | 源码错误及调用路径诊断 | Java Feature Envy 检测与方法移动建议 |
| 输入 | 支持语言源码 + 可成功执行的构建 | Java 源码 + 固定特征提取器、模型；或归档特征 |
| 输出 | 错误类型、文件行号、原因、bug_trace | Move Method、源方法、目标类 |
| 跨项目配置 | 路径、正常构建命令、编译依赖 | 项目路径，复用固定提取器和模型 |
| 业务规则 | 不需要 | 不需要 |
| 准备成本 | 编译环境；本轮固定 Ubuntu/JDK 容器 | 旧 Python/Keras 依赖、JDK、模型大文件；环境已归档 |
| 核实范围 | Java 跨项目与空指针对照 | 论文样例重放及新源码功能运行 |

Infer 论文为 *Local Reasoning About the Presence of Bugs: Incorrectness Separation Logic*，DOI [10.1007/978-3-030-53291-8_14](https://link.springer.com/chapter/10.1007/978-3-030-53291-8_14)。执行的是 Infer 1.3.0 Pulse，不是 CAV 原始归档程序，也不是 OOPSLA 2022 Pulse-X 原型。

feTruth 论文为 *Deep Learning Based Feature Envy Detection Boosted by Real-World Examples*，DOI [10.1145/3611643.3616353](https://doi.org/10.1145/3611643.3616353)，[会议官网](https://2023.esec-fse.org/details/fse-2023-research-papers/112/Deep-Learning-Based-Feature-Envy-Detection-Boosted-by-Real-World-Examples)确认研究论文身份。[作者代码](https://github.com/lyoubo/feTruth)与[论文归档](https://doi.org/10.5281/zenodo.8267775)均可对应。FSE 与 CAV 在[本地 CCF 目录](../references/ccf-seventh.pdf)分别为第 27、41 页 A 类。

两项均是源码侧基线，覆盖程序错误与方法职责两个不同任务。实际部署输入由 NeuVector 提供，符合原始要求对全部基线集合的输入覆盖要求。源码模型建议和静态告警都不等于已确认缺陷，也不自动形成完整成熟度评估或修复闭环。

feTruth 的论文重放 16/16 一致与新 jsoup 源码 180 条候选属于不同工作流；模型差异保留在[诊断记录](../results/fetruth-model-diagnostics.json)，不得混用。本项目 Java 示例的 1 条建议尚未执行方法移动和业务回归。

最新内容统一见[图文调研报告](成熟度评估baseline调研结果.md)、[全部输入输出类型](基线输入输出清单.md)、[复现指南](两项学术基线复现.md)与[当前选型清单](../baselines/academic-review-manifest.json)。本轮复用已有结果，未重跑全量实验。
