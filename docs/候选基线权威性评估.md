[Infer 论文](https://link.springer.com/chapter/10.1007/978-3-030-53291-8_14)、[feTruth 研究论文页](https://2023.esec-fse.org/details/fse-2023-research-papers/112/Deep-Learning-Based-Feature-Envy-Detection-Boosted-by-Real-World-Examples)、[CCF 本地目录](../references/ccf-seventh.pdf)。CCF 目录第 27 页列 FSE、第 41 页列 CAV 为 A。论文等级只用于准入，不能替代工具效果和适用性验证。

feTruth 不需要逐项目业务规则，但只覆盖 Java 方法职责问题，首次安装需旧模型环境；已有[模型差异记录](../results/fetruth-model-diagnostics.json)。Infer 需要正常构建和完整依赖。两者均不覆盖全部业务语言和部署问题。

商用保持 Microsoft AppCAT for Java、SUSE Security/NeuVector。部署输入由 NeuVector 承担；付费支持、生产效果与所有安全能力没有因此被验证。来源与当前状态已同步到[结构化依据](../references/authority/candidate-evidence.json)。
