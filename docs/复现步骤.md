## 商用基线

仅保留 **AppCAT for Java** 和 **SUSE Security／NeuVector 开源发行版**。两项前后实验已完成，安装条件、完整命令、版本校验、原始结果与清理步骤见[两项商用基线复现](两项商用基线复现.md)。

已有本机环境下，AppCAT 入口为：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/reproduce_appcat.ps1
```

NeuVector 先按指南启动本地 API 端口转发，再运行：

```powershell
.runtime/commercial-venv/Scripts/python.exe scripts/reproduce_neuvector.py --kubeconfig .runtime/tools/maturity-kubeconfig --password-file .runtime/neuvector/admin-password.txt --output "results/commercial/neuvector/$(Get-Date -Format yyyyMMdd-HHmmss)"
```

验收必须同时核对原生输出和业务行为，不能只检查退出码。AppCAT 目标规则命中 1→0，NeuVector 原生根用户标记 true→false；两项业务行为保持。NeuVector 权限对照的全局评分未下降；后续已有节点 CIS 130 项和容器 CVE 27 条报告，详见主调研文档，不能将不同实验混算。

## 学术基线

当前学术基线为 **Infer/Pulse + feTruth**。本机已有环境的重跑入口如下：

```powershell
python scripts/reproduce_academic.py --tool infer --output results/academic-rerun/infer
python scripts/run_fetruth_project.py --source baselines/sources/maturity-evaluate/examples/comprehensive_test_repo/java_app
```
